# Imagens

Onde colocar cada coisa. Depois de subir um arquivo aqui, cole o caminho no
campo correspondente do painel (ex.: `/assets/img/cases/arrivo.jpg`).

| Pasta          | O que vai aqui                          | Formato sugerido            |
| -------------- | --------------------------------------- | --------------------------- |
| `clientes/`    | Logo do cliente, mostrado na capa        | SVG, ou PNG com fundo transparente, altura ~200px |
| `cases/`       | Imagem de capa de cada case              | JPG ou WebP, 1600×900       |
| `depoimentos/` | Foto de quem deu o depoimento            | JPG quadrado, 400×400       |
| (raiz)         | `favicon.svg`, `og-padrao.png`           | —                           |

## Ainda faltam

- `og-padrao.png` — 1200×630. É a miniatura que aparece quando você cola o
  link no WhatsApp. Sem ela, o link vai sem imagem.
- `apple-touch-icon.png` — 180×180. Ícone quando o cliente salva a proposta na
  tela inicial do celular.

## Peso das imagens

O cliente costuma abrir a proposta pelo celular, muitas vezes no 4G. Vale
exportar em WebP e manter cada arquivo abaixo de 300 KB — a página inteira
carrega mais rápido que a primeira rolagem.
